## 3. The validation ladder — give separate verdicts, never collapse them into “accurate”

Prepare a per-claim matrix with these levels and explicit available evidence:

**L0 — input/data and reproducibility:** Real tree identities, plot polygons, geographic site, species, DBH/height/crown, juveniles, original measurement year, management event/cut masks, setup conditions, licence and version hashes. Distinguish measured trees from synthetic periphery/saplings and projected recruits. Repeated runs share a controlled baseline, denominator and compatible output definitions.

**L1 — software logic and conservation (CCF's internal truth):** Spatial membership/rack/tile ownership has no double-counting; cuts occur only for real eligible living IDs after genuine player approvals; proposal-only/no-cut makes NO harvest, cost or change attributable to felling; area/tree/BA/cash/event summaries reconcile with authoritative records; no duplicate tree IDs or work orders; annual repeated cycles use true changed stand state. **Samsara2 cannot prove CCF's Work Plan, rack identity, persistence or approval logic**. These need CCF-side invariants, independent tests and separate later native verification.

**L2 — cross-model behavioural plausibility:** On *equivalently defined* initial tree populations and *deliberately identical treatment designs*, examine whether CCF and Samsara2 agree on the **direction of responses** (not numerical equality) for density, BA, DBH distributions, canopy/light, mortality, regeneration, and broad species shifts. A model disagreement is an **investigation prompt**, not automatic proof that CCF is wrong. Record conditional models/site and stochastic uncertainties.

**L3 — quantitative cross-model comparison:** Only if both systems have truly aligned initial states, measurement conventions and parameter meanings. Report differences and uncertainty intervals (or bootstrap/per-replicate distributions where justified), over multiple initialisation draws and observation horizons. **Agreement of two models is not independent real-world accuracy**; shared assumptions can produce shared errors. No calibrated Irish numerical thresholds from Samsara2 alone.

**L4 — predictive ecological accuracy against independent field reality:** Requires real plots with legally usable inventory at time T, recorded management actions, **independent repeated observations at T+k** (trees/regeneration/mortality), known site/weather/confounders and appropriate withheld validation data. Assess measured-versus-predicted error, bias and uncertainty by site/species/size class/treatment/time; use independent holdouts rather than tuning and testing against the same plot. **No existing #456/#461 result establishes L4**. If the required follow-up observations or licences are unavailable, explicitly mark **L4 NOT VALIDATED**, not APPROVED.

These levels should have separate CCF test verdicts: PASS/FAIL/INCONCLUSIVE/NOT TESTED/NOT APPLICABLE. Distinguish internal *correctness*, mechanistic *plausibility*, cross-model *agreement*, and empirical *accuracy*.

## 4. Falsifiable comparison experiments the Manager must specify — NO local runs in this task

Design a compact, preregistered experimental matrix with exact input/observable/acceptance meaning and failure handling. Propose it as a **future execution packet**, not executed research.

### A. Sanity and shared baseline controls

- Start with **one neutral tree table**: ID, species, position x/y, DBH, height/age when available, crown/competition when available, live/dead, juveniles and time; record 2D mapping, metric units and species/site sources. Convert to both engines **without inventing unmeasured field values**; any required estimated inputs are labelled defaults. Hash source and each transformation.
- Separately audit source plot mask: martelosim 1.17 ha rectangle versus independent approximately 1.10 ha marteloscope; CCF's five-rack finite masks, track/clearing exclusions, tree ownership and denominator. Never compare per-hectare outcomes until the **same population and same net valid area** have been selected.
- First run **no-cut**, no new planting, and no automated Work Plan orders, with matching time stepping. Test conserved IDs/initial BA and report every parameter-definition difference before using trend comparisons. If models cannot represent a common species/stand consistently, report **not comparable**, not a forced test.
- For stochasticity, use **one fixed prepared inventory** within each primary comparison, 5+ replicates per treatment as a starting design, then a smaller **multi-prepare** sensitivity set because #461's results depended on one random setup; design adequate repetitions from observed variance rather than claiming 5 universally sufficient.

### B. Selection-pattern controls (same basal-area removal, different trees)

- T0 No-cut; T1 thinning from below; T2 removal of a small number of large trees; T3 **genuine manual spatial competitor release** around known crop-tree IDs (explicit selected pairs/5m or other **hypothetical test radii**, not assigned by the unverified Samsara focal algorithm); and T4 optional spatially clustered versus distributed cut-set comparison **at the same BA**.
- Use explicit cut-ID masks (where Samsara and CCF both accept them), log executed cut IDs, dates, BA removed, species/size classes and retained crop IDs. Reject any “equal treatment” claim if one engine cuts different trees, changes baseline, or applies its own alternate policy. If manual cut-set replay is unavailable on one engine, document gap and retain only model-specific results.
- Measure time0 and subsequent annual/5/10/20/30-year trajectories, contingent on actual model support. Do not call differences in initial regeneration interpretation a treatment effect. Report light units and whether light is per cell, ground or crown; tree density and mortality stages, juvenile/recruitment thresholds, radius/edge assumptions and volume definitions.

### C. Multi-rack inference-specific controls

**Samsara2 has spatial tree physics, not the CCF rack-plan/Work Plan authority.** Use rack/service-area masks as **external comparable analysis groupings**; do not pretend Samsara2 internally understands CCF Rack V2, player approvals or prescription persistence.

Compare (i) exactly the same tree-level cut-set applied in one served area, (ii) the identical rule executed in multiple genuinely comparable areas, and (iii) comparable masks that are deliberately different in DBH distribution, basal area, species/age, edge/light and juvenile constraints. Track full-tree annual responses and compute independent summaries by *disjoint* rack/tile polygon, while respecting cross-boundary canopy/competition.

**Essential falsification:** show an intentionally *unmatched* rack where transferring a sample rule would yield an implausible selection or unsafe local BA/recruitment outcome; the **CCF management policy must refuse/Manual that rack**. Samsara2 can help expose ecological consequences if cuts are applied, but it **cannot determine by itself which CCF transfer guard is officially correct**. The safe match/reject policy still needs forestry evidence and user-approved D-065/D-076/Objective2 specification.

### D. Repeated intervention, not just a one-off thinning

For each treatment, include an untreated control and two intervention years separated by genuine annual advances, plus variants with no-work years. Record in-world live trees, growth, mortality, regen, light and year-specific work identities. Compare relative trajectories, not a copied “source rack Year +10” prediction pasted to the other racks.

**No paper-balance tricks:** a rack proposal does not make a tree disappear; model-visible effects occur only after a confirmed tree action is executed, never due to a coverage overlay. Economics/work-order identity is a separate **CCF correctness** gate, not Samsara2 ecological accuracy.

## 5. Quantitative metrics and analysis discipline

Require a common glossary and units for: trees/ha, alive stems, eligible adult trees, DBH distribution and quadratically mean DBH, BA m²/ha, tree-level removal BA, volume m³/ha (not equivalent without merchantable threshold), mortality N/ha/year, recruited trees by threshold, sapling/cohort count per area and height class, light irradiance (MJ/m²/yr vs proportion), crown area, species split, plot/core masks, and dates/intervals.

At minimum:
- A **first-state concordance table** with tree IDs/count, area, summed basal area, live DBH quantiles, species, juveniles, and all unmatched fields.
- **Internal conservation checks** for CCF work order/actual cut identity, BA and per-rack ledgers.
- Treatment-effect difference versus the **matched no-cut control within each model**, then **difference of those effects across models**. Avoid comparing raw final numbers if initial dynamics and site differ.
- Means, SD, replicate scatter, within-seed/prepare pairing only when actually available, confidence/uncertainty ranges when justified, and sensitivity across multiple preparation draws and alternative model input assumptions.
- Rank **robust direction**, **weak/inconclusive**, **opposite**, **not comparable**. Predeclare approximate effect-sign criteria and what would count as genuine contradiction; never cherry-pick favourable CCF outcomes.
- Negative tests: invalid source plot dimensions, mixed species forced through Sitka-only fit, no treatment, proposed-only/zero approved work, repeated marks, dead trees selected, double-counted corridor, unmatched destination, missing prior source execution, unobserved site data, stale source year, later intervention after heavy thinning, and unrealistic regeneration class transfers.

**Do not** invent empirical accuracy percentages, calibration scores, Irish “correct” BA percentages or standard crop-tree spacing. Existing game thresholds and Samsara example caps are independently labelled **GAMEPLAY CALIBRATION** or **DEMONSTRATION SETTINGS**, not forestry measurements.
