## 0. Executive verdict and the owner's Prélenfrey proposal

**DECISION: GO for a strictly offline, falsifiable reference-plot model-comparison programme; NO-GO for claiming independent ecological accuracy, exact future-output parity, Irish numerical calibration, code transfer or production integration.**

The owner's proposed strategy—recreate the actual **Prélenfrey marteloscope in France**, give a separate 2D CCF research interface the **same tree IDs and player-marked cut IDs**, and compare its responses with the established **martelosim → Samsara2/CAPSIS** workflow—is a sound **controlled benchmark hypothesis**. It tests whether our representation of *the mapped plot and actions* is right, and whether trends from the two ecological models agree when all inputs are really comparable. It **does not** prove that one model is the true ecological future, and “working perfectly” should never mean tuning CCF until every predicted number equals Samsara2.

Three different reference notions must remain separate:

1. **Field observation:** a real historical tree inventory at time T (positions, diameter, species, recorded standing quality); credible **L0/L1** data anchor. A documented *participant's chosen marks* describe a human judgement, not one uniquely correct treatment.
2. **Model forecast:** Samsara2's simulated Year T+1…T+n after that tree marking. **martelosim is an R preparation/marking/orchestration/report wrapper around Samsara2, NOT a second independently calibrated ecological forecast**. Model-to-model comparison can challenge CCF but cannot establish empirical truth.
3. **Observed future:** actual remeasured tree IDs, growth/mortality, recruitment, stand light, site and management at later time T+k. **Only this supports L4 ecological predictive-accuracy evaluation**, ideally with withheld noncalibration plots and Irish species/sites.

**Immediate recommendation:** work toward a **licensed Prélenfrey frozen-baseline, exact-cut-ID, matched/no-cut comparison**, only after the rights and representational gates below. Use its output as a *diagnostic comparator* for an offline CCF ecology testbed, **not as the biological equation set** that must be imported to Ireland. Alongside it pursue separate authentic *Irish* longitudinal Sitka, sessile oak and beech field observations; these are a different acquisition problem. No work here changes the user-requested eventual 2D/3D shared-state player experience.

## 1. Exactly what upstream and prior experiments establish

### 1.1 Official workflow and model lineage [DOC]

- Official [martelosim quick guide](https://martelosim.lessem.forge.inrae.fr/articles/martelosim.html), [package index](https://martelosim.lessem.forge.inrae.fr/reference/index.html), [inventory function](https://martelosim.lessem.forge.inrae.fr/reference/new_inventory.html), [prepare command](https://martelosim.lessem.forge.inrae.fr/reference/write_prep_samsara_cmd.html) and [simulation command](https://martelosim.lessem.forge.inrae.fr/reference/write_samsara_cmd.html) describe importing a plot's Excel inventory, converting it to Samsara input, supplementing missing Z/saplings, adding virtual peripheral trees, recording marked-tree choices, running forecasts and producing report/map outputs. First thinning can use actual entered cut marks; later thinning may use inferred multi-criteria strategy rather than replayed human decisions. This policy distinction matters for multi-cycle validation.
- The docs explicitly say a tree's Z coordinate may be **approximated** from average slope and exposure, and optional field attributes may be supplied as **defaults or generated virtual saplings**. Those are simulation assumptions, not measured Prélenfrey observations. The guide describes periphery generation to handle border light, which must be **excluded from core reporting while retained if needed for physical boundary response**.
- Public upstream package [martelosim](https://forge.inrae.fr/lessem/rpackages/martelosim) is **MIT**; [Samsara2 published process/evaluation literature](https://www.sciencedirect.com/science/article/pii/S0304380015002884) concerns spatially explicit individual-tree dynamics and its calibrated domain. The 2015 Courbaud et al. study explicitly distinguishes process calibration, qualitative and quantitative evaluation, global sensitivity and recalibration. It does **not** certify this particular modern Prélenfrey run as remeasured ground truth or certify any Irish CCF species.
- **Version caution:** the publicly visible **older guide/manual** still references CAPSIS revision **22711** and some indexed docs show martelosim **0.1.2**. The genuinely tested #456/#461 **compatible pair** is CAPSIS/Samsara2 **4.2.7-22961** (Java 8) with **martelosim 0.1.3**. The latter is visible in INRAE's newer [vignette index](https://inrae.r-universe.dev/articles). Lock exact binaries, dependency manifests and input-format versions in future experiments, rather than mixing documentation revisions.

## 3. Common data contract, translation and irreducible mismatches

**Proposed canonical *offline* neutral table (no production schema):** \`plot_id, inventory_date, tree_id_original, species_taxon, x_m, y_m, z_m [measured/estimated], dbh_cm, height_m [measured/imputed], live_state, dbh_inclusion_cm, crown_dimensions [measured/imputed], age_or_cohort [if known], juvenile_class, field_quality_or_TreM [if licensed], action_at_date, source_provenance_flag, record_hash\`. Separate \`site_metadata\` (polygon coordinates/CRS/local origin, terrain/slope, soil, altitude, exposure, climate time series, sampling design, data licence), \`treatment_events\` (date, tree_id, intended vs approved vs executed, felling/extraction vs deadwood, source record, work year), and \`output_dictionary\` (species/size/area/units/time).

For each comparable metric Y, model M, treatment j and time t, report the **within-model treatment effect** \`Δ(M,j,t) = E[Y(M,j,t)] − E[Y(M,no-cut,t)]\`, then the **cross-model contrast of treatment effects** \`D(j,t) = Δ(CCF,j,t) − Δ(Samsara,j,t)\` **only when** units, area, cohort threshold and ecological meaning align. **Measurement glossary and units (mandatory outputs):**

| Measure | Unit/convention | Key comparison caveat |
|---|---|---|
| N, density | total unique alive adult stems, N/ha using legitimate common **net** polygon; mortality N/ha/year separately | Distinguish killed/removed trees vs natural deaths and cross-stage recruits; 7.5cm threshold not necessarily CCF's |
| Basal area | \`Σ π(DBH_cm/200)^2\` m²; divide by core ha for BA/ha | Count shared removed tree once; dead vs living and the **year of DBH** matter |
| DBH | cm; raw quantiles and \`Dq = sqrt(mean(DBH_cm²))\` | Mean DBH ≠ Dq; recruits change denominators |
| Light | MJ/m²/year under canopy, percent full light, class distribution, relative model light | Not interchangeable with arbitrary CCF cell-light scores; report actual unit/height/stage and spatial grids |

| Crown/site | crown size, elevation/Z, slope, aspect, microclimate assumptions | Estimated Z and virtual periphery can materially alter light results |
| Volume/quality/cash | biological vs merchantable volume, site pricing, work order and actual settlement | French grade/price and model economy do not validate Irish quotes or job grouping |
