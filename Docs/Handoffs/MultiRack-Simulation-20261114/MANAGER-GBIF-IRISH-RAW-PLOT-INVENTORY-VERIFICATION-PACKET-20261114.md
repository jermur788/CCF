## 3. Gate 2 — field geometry and independent immediate metrics

For each candidate that passes Gate 1, evaluate:

- **Plot geometry:** an official plot polygon or unambiguous measured grid corners and units, local coordinate origin/reference, orientation/angle convention, axis handedness, raw \`verbatimCoordinates\` syntax and known corner/plot markers. Do not confuse GBIF WGS84 plot-point location with individual x/y. If only approximate image/grid is available, “2D exact” remains **NOT VERIFIED**.
- **Transforms:** independently parse all permitted stem positions to a common local x/y in metres. Verify complete unique IDs, finite values, no coordinate ambiguity, no misread decimal degrees, no unclaimed duplicates, and explain boundary/edge/multi-stem exceptions. Name missing slope/crown/seedling/understory fields rather than invent them.
- **Area:** compute actual sampled core area if polygon verified; explicitly distinguish approx 1ha pedagogic convention from the area of the exact field plot and invalid strips/track omissions. Stems must be counted against the proper surveyed mask; use m² → hectares.
- **Basal area check:** for one uniquely identified *living qualifying adult stem*, \`BA_tree = π(DBH_cm/200)^2 m²\`. Sum once across eligible unique adult IDs; report total BA m² and BA m²/ha using exact verified core polygon. Report N, N/ha, DBH mean and quadratic mean and valid size classes. If area/threshold uncertain, show **BA total** without pretending per-hectare area known.
- **Reconciliation:** explicit raw row→tree map table (at least small non-sensitive *structural examples*), handling of dead stems and multi-measurement DBH duplicates, time stamp, species unknown and coordinate missing flags, boundary/edge problems, and computed first-state values. Research output need not disclose bulk tree coordinates or publish derived proprietary site geometry.

**Minimum acceptance for limited real 2D research reconstruction** (all four): (i) identifiable licenced full qualifying stem table, (ii) unique tree IDs + species + DBH/status, (iii) verified local x/y & **true area/boundary**, (iv) archived reproducible source and lawful permitted use. Any failure => **CONDITIONAL / NOT VERIFIED** and no exact-real claim; a static schematic may still be possible but must be explicitly labelled approximate.
