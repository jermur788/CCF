### 2.1 Input fork, initial inventory, geometry and isolated files

**Proposed v1 input:** original, verified **synthetic P0 fixture only**, with immutable **full file SHA-256 + validated P0 snapshot hash**, stable IDs, source class, inventory age/year provenance, original statuses and P0 fixture version. Do not import a P0 post-executed thinning plan, live APPROVED/PENDING_WORK approval or prior P0 annual-step events in v1. P1 creates its *own* independent intervention history after fork. This avoids conflating P0's no-growth calendar event with ecological growth and makes migration a later separately reviewed feature. **This is a proposed C-1A owner choice**, not automatic acceptance.

**File namespace proposal:** separate P1 root \`format\` and schema namespace, for example \`ccf-sitka-adult-p1\` and version 1 (these names are not accepted API). P1 reads an explicitly imported verified P0 source only; normal P1 save/load has a distinct extension, guarded root, version refusal and no production CCF save access. **Do not edit P0's existing .gitignore**, which is owned by its qualified lab branch. Evaluate a P1-owned *sibling* directory/service with its own ignore and secure file root, or a separately owned parent; show tradeoffs with P0 Host reuse, localhost security, handle-relative atomic I/O and independent launch. **Before any code P1-02** the team must decide the exact P0 lab source lineage: it is on the separately qualified P0 feature branch, **not on main**. A new conceptual P1 folder is NOT proof such code already exists.

**Geometry proposal:** use exact source-equivalent **square centred** stands and declared horizontal x/z mapping for Unity parity; the P0 \`oracle-quarter-ha\` fixture is a **50 m corner-origin square (0.25 ha)** and might be re-centred to ±25 m as an explicit versioned adapter transform, but has only 3 trees and will not exercise density mortality. Other P0 polygon areas are clearly a **non-parity extension**, never silently called equivalent to \`standSizeMeters²\`. Include dense fixture and boundary/edge cases independent of the demo. Mark area/XY mapping, source stand origin and tree-position numeric conversions in one manifest. Do not claim it reproduces Mono float roundoff until a future Editor capture.

**Testable negative cases:** imported file with wrong format/schema/hash; unvalidated post-execution snapshot; malformed/unknown version; source ID collision; P0 dead with no cause/year; P0 plan accidentally treated as ecological event; P0 reader accepting P1; P1 reader accepting production CCF save; file/symlink/path traversal, special-file and mixed root regressions. These are future *tests to design*, not executed proof.

### 2.2 Annual ecology, population and source provenance

**Proposed CCF-rule study domain:** *closed pure-Sitka, all living trees treated as explicitly synthetic Mature-equivalent, Reference growing-space demand; no recruitment, regeneration, storm, browsing, pruning or mixed species*. "Mature-equivalent" is an **experimental modelling assumption**, **not a claim** that small-DBH P0 stems are real mature Sitka. Roughly 10% of live P0 trees are below the lab's action threshold; they still belong in source CCF all-living CI, RD, growth/mortality, while P0 action-eligible subset must be shown separately. Maintain **no-growth P0 behaviour unchanged**. Source SiteProductivity=1 is source-current behaviour, not a forestry productivity forecast. Include initial P0 dead only as **pre-inventory dead, cause/year unknown**, never a new ecological mortality event.

**Proposed initial crown:** record a specifically labelled **synthetic** crown radius, potentially the source crown target computed from initial DBH when competition is absent, with documented clamps; do not imply original P0 contained measured crown data or historically observed radial release. Keep exact formula and handling for tiny DBH and dead stems visible, plus alternative for arbitrary synthetic initial crown if a reviewer disputes target initialization. **Initial age, ecological year, seed, RNG and growth model version must be explicit and independent of the P0 inventory calendar year**; never infer ecology year from a Gregorian label or conflate the random and growth model selectors. Do not hardcode an arbitrary Irish site index as truth; identify which fixture attributes actually exist versus must be synthetically supplied.

**Annual order to preserve from current source:** executed work before a year's advancement changes next growth CI; inside annual advance ecologicalYear increments; pre-growth Hegyi neighbours/CI; growth DBH and age/height (Mature-sensitive getter); crown relaxation using updated DBH and pre-growth CI; then post-growth stand RD/natural mortality and deterministic integer-hash RNG rolls, with suppressed-victim priority; no new second growth after mortality. Storm/juvenile/regeneration not simulated in closed lab. Same-year approval/mark/queue does not fell. Tiny-area singleton >1 RD escape and exact 8 m inclusive neighbour boundary are required counterexamples. **Source-derived rules are not empirically verified Irish hazard laws.**
