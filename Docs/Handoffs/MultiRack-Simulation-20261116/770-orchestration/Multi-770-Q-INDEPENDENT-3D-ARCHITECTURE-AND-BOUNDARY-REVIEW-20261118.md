### 4.1 What I checked and found sound

- **Phase A conformance (A).** Both dossiers state that they are proposals, NOT RUN, and not self-approved, and both list open owner decisions. A1 §8 never ranks or selects a runtime. Apart from Q-05, Q-09 and Q-11 above, I found no place where either quietly decides technology, scope, fidelity or policy.
- **2D reference is not a 3D API (B).** Both state that `ccf.h0a.core-read` v1.0.0 is restricted to H0-A and is not an approved 3D API (A1 §2.1, §3.4, §8.5; A2 §1.1, F-6, §8). A1 handles R-758C's historical DRAFT header correctly by reading it together with the R-758A adoption.
- **Year semantics (C).** Year0 is presented as the authoritative baseline of the synthetic experiment and the only first-slice scene. Year1 is historical, locally qualified and excluded. Year2 and marking are DRAFT and are not renderable authority. Apart from Q-10, both are consistent.
- **Evidence integrity (D), A1.** Every A1 value I spot-checked matches R-758C: transform ID and formula; seeds `6390001` and `20261116`; SHA-256 `bcaaa5c3…57c4` and 32,567 B; `P30-001…P30-100`; the four availability states; `hegyiCi` NotEvaluated; `healthScore` Unavailable; `stemsPerHa` Unavailable; `[0,30000)`; polygon; elevation 0; `MatureEquivalent`; `crownRadiusM` as a radius; excluded systems including canopyLight and regeneration; `contentHash` ignored for trust; 2D drawing from integer mm, not centredX/Z; strict `dbhMm < 170` as an annotation only. I found no invented coordinate, coefficient, performance figure, quota, screenshot or PASS in either dossier. Both use symbolic thresholds (`T_FIRST_RENDER`, `T_FRAME_P95`) or none. A2's 4.5:1 and 3:1 contrast figures are standard WCAG values, not invented.
- **Non-overlap (F).** Each commit adds exactly one file under `770-orchestration/`, which I verified with `git diff --stat` against `ff03290a`. Neither cites or edits any `769-orchestration/` file or any #769 source. Both state that they read no fixture, P0, #687, #710 or #725 source. Scenario One appears only as an exclusion, plus Q-16. No code, `.meta` or config was changed.
