### 4.1 What I checked and found sound

- **Phase A conformance (A).** Both dossiers state that they are proposals, NOT RUN, and not self-approved, and both list open owner decisions. A1 §8 never ranks or selects a runtime. Apart from Q-05, Q-09 and Q-11 above, I found no place where either quietly decides technology, scope, fidelity or policy.

- **Evidence integrity (D), A1.** Every A1 value I spot-checked matches R-758C: transform ID and formula; seeds `6390001` and `20261116`; SHA-256 `bcaaa5c3…57c4` and 32,567 B; `P30-001…P30-100`; the four availability states; `hegyiCi` NotEvaluated; `healthScore` Unavailable; `stemsPerHa` Unavailable; `[0,30000)`; polygon; elevation 0; `MatureEquivalent`; `crownRadiusM` as a radius; excluded systems including canopyLight and regeneration; `contentHash` ignored for trust; 2D drawing from integer mm, not centredX/Z; strict `dbhMm < 170` as an annotation only. A2's 4.5:1 and 3:1 contrast figures are standard WCAG values, not invented.
- **Non-overlap (F).** Each commit adds exactly one file under `770-orchestration/`, which I verified with `git diff --stat` against `ff03290a`.
