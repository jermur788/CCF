## 3. Model, unit and authority dependencies to settle *before* cross-system production

1. **Spatial/time identity:** 3D uses individual world-position trees plus 5 m ecology cells where applicable; 2D uses a synthetic 30 × 30 m closed 100-Sitka adult domain and in-memory yearly frames. D-083 Compact30 has identical outer length **but different roster, ecology, scene, provenance, no-rack goal and player workflow**. No spatial equivalence from shared size alone. Annual timesteps are useful common language, not proof of the same transition.
2. **Quantity provenance:** competition index is a dimensioned model summation rather than a universal observed “% of growth”; per-neighbour share is a relative decomposition. 3D cell Light is a bounded relative simulation variable; don't call it lux or percentage daylight measured in Ireland. Seed rain is a species-keyed model intensity, not tree count; cohort Density needs an explicit unit/normalization; browsing probability is not an Irish deer-density conversion; 3D cash is integer cents, timber volumes use m³ (the yield/economy layer uses integer cm³ internally), while 2D BA is m²/ha. Keep input, denominator, radius, year, site and estimator version in the model contract.
3. **Ecological scientific strength:** pure-Sitka existing behaviour must remain a compatible case where a future shared density architecture is considered; Oak/Beech occupancy is currently ordinal; do not import Central European DEC/DMC coefficients as Irish truths or invent a generic mixture bonus. Evidence sources are indexed in Docs/Project/research-index.md; the Species Evidence Pack/Growth-Density composite and GROWFOR extraction are **supporting research, not adopted CCF parameters**. For regeneration, seed supply + light + substrate/site + browsing + understorey + time are distinct bottlenecks. A synthetic 0.09 ha closed field has large boundary/seed-source ambiguity.
4. **Protected systems:** frozen P0 four-way source/reference (pinned SHA-256 9a99f78131a348032a0342b2ec3dc2b671c0455ab60fee504761e0e82e1934b3), 2D #849/#874 fences, immutability, determinism, replay and accepted exact-ID Fell; Unity Legacy40, Enlarged80, frozen Reference Future v1, old saves and profile isolation. Neither a spec nor this research document grants changes. A standalone 2D diagnostic should not introduce a new save schema accidentally.
5. **Authority/review:** D-059/060/061/062/083/084/085 govern Scenario One goals; [#881](https://github.com/jermur788/CCF/issues/881) owner feature-parity intent and the [approved first-pass spec](https://github.com/jermur788/CCF/blob/docs/multi-863-881-firstpass-competition-unity-ui-spec-20261120-v1/specs/multi-2d-competition-unity-ui-firstpass-v1/spec.md) govern #882 only. Novel light/recruitment/species/real G1 mechanics **SPEC REQUIRED**: reviewed spec.md, plan.md, tasks.md and checklists/requirements.md, explicitly APPROVED before production. G3 calibration/fixture policy, G4 shared contracts/save/integration and G5 product/model scope cannot be self-approved by a research worker.
