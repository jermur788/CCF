## Why the owner wants these changes — explicit intent versus Manager inference

**Directly expressed owner intent:** make the 2D forestry map feel and operate much closer to the existing Unity Stand Map, not like a long scrolling technical dashboard; see and compare tree competition intuitively; select the intended neighbouring Fell tree quickly; avoid useless IDs, forced explanations, speculative tree-health diagnoses and excessive map controls; make zoom and pan understandable in one desktop viewport; ultimately access the substantive forestry information already available in 3D.

**Manager interpretation, NOT a quotation or separate approved mechanic:** the desired loop is **see a recognisable stand → click any tree → understand its neighbours and trade-offs → designate retained Crop if desired → click one of the ranked competing trees and make a deliberate Fell proposal with minimal friction → inspect/approve/execute Work Plan → advance time and visually understand change**. The owner is optimising for *player comprehension, agency, low click/typing burden, credible ecology and meaningful visual feedback* rather than administrative data entry or proving internal IDs/tests.
