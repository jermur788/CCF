## Why Candidate B differs conceptually
Current code assigns a **single circular crown radius** to a tree based on open-grown DBH potential multiplied by scalar Hegyi competition, and relaxes toward it at 0.15 per year. Neighbours differ by bearing and distance, so scalar suppression can incorrectly limit a crown equally on all sides. Candidate B represents competition in **eight directional sectors (N, NE, E, SE, S, SW, W, NW)**, each with its own pressure and plausible realised radius, then outputs **one area-equivalent circular radius** to the existing unchanged /multi SVG interface. Eight sectors is a proposed numerical resolution, not a measured forestry constant; check sensitivity against 12/16 sectors offline. No hard 'divide plot area by stem count', hard Voronoi nonoverlap, arbitrary 2.9m cap or compulsory visible gap.

### Proposed mathematical structure — all free parameters UNFITTED

1. **Potential envelope, not current plantation width.** For tree i with DBH D_i in cm, use the existing **open-grown reference** Rpot_i = 0.9415 + 0.07635 × D_i metres (Tabbush & White 1988). Treat this as an upper envelope to be checked for validity, not measured crowding response.
2. **Local directional pressure.** For each sector k around tree i, find relevant living neighbours j at their actual X/Z coordinates. A research model may use:

       C[i,k] = SUM_j { angularWeight(k,bearing_ij) × (DBH_j/DBH_i)^p × exp(-distance_ij / L) }

   where angularWeight declines away from sector k (e.g. max(0,cos angular difference)). p (size effect) and L (in metres, reach) must be fitted or bounded using Sitka stem-mapped crown data. Height/crown-length dominance may be added **only if independent data justify it**. Avoid using current arbitrary CI50=5 as though it is empirical crown calibration. Do not count dead/felled neighbours.
3. **Realised sector targets.** Example smooth, deliberately non-hard-exclusion relationship:

       targetRadius[i,k] = Rpot_i × exp(-beta × C[i,k])

   beta >= 0 is a fitted sensitivity, not a value selected to reveal ground. This allows crowns to **overlap**, and one side can grow farther into a release gap than a crowded side. If measured data favour a different monotonic functional form, compare it offline rather than treating exponential form as science.
4. **Starting crown state:** reconstruct plausible realised sector radii at year 0 from actual positions, DBH/height, stand history when known, and measured-style crowding; otherwise explicitly label starting history uncertain. The existing 30m P1 DerivedManifest starts crowns at **CI=0 open-grown potential**; verify whether MA-A/MA-B share this origin. No silent change to that frozen fixture.
5. **Growth after felling:** on each genuine annual step, recompute pressure using surviving neighbours and newly grown DBHs; permit expansion toward target using a **measured/bounded maximum lateral rate** and crown age/vigor response, not instant gap-filling:

       nextRadius[i,k] = currentRadius[i,k] + min( vMax_i, gamma_i × max(0, targetRadius[i,k] - currentRadius[i,k]) )

   Here vMax_i (metres/year) and gamma_i (per year) are empirical/calibration unknowns; the example does not model sudden physical contraction or dieback, which would require separate evidence. Do not assume one year's thinning immediately increases all eight directions.
6. **Unchanged SVG contract.** An internally directional crown of eight sector radii has area A_i approximately (pi/8) × sum_k radius[i,k]^2. Export the equivalent circle radius:

       R_equivalent_i = sqrt( sum_k radius[i,k]^2 / 8 )

   This keeps the existing one-number CrownRadiusM field and current circular SVG behaviour unchanged **if** the owner ultimately selects Candidate B. It is an **area-equivalence approximation**, NOT an exact map of asymmetric crowns. Report the shape/coverage error of replacing a sector polygon with an equal-area disk, particularly near openings, before claiming accuracy. If that loss is too large, this variant should be rejected rather than quietly modifying the map contrary to owner instruction.

### Explicit proposal limits
- This is a plausible **mechanistic structure**, not fitted Sitka coefficients. Only the open-grown envelope constant has existing documented provenance; all directional weights, p/L/beta, expansion ceilings and starting-crown equilibration require evaluation.
- Competition pressure may be low on one side but trees still physically shade/overlap; radius is not ground light, LAI, biomass or recruitment.
- Real crowns can remain overlapped after more than ten fells; do not turn 'show soil' into a forced model acceptance target.
- Fitting sector asymmetry from total crown width alone is underdetermined. Prefer directional crown surveys; otherwise compare the simpler scalar model and disclose inability to establish directional precision. Model complexity is a liability if its data cannot support it.
