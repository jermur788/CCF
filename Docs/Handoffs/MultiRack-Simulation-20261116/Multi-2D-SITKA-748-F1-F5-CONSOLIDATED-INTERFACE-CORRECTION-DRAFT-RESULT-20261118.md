## 2. F1 — proposed canonical observation stages, availability and exact numeric kinds

**Normative wording if independently reviewed and explicitly approved:** a versioned \`ReadObservation\` is a detached read-only **complete tree roster** plus one stage-identified aggregate/availability envelope and an F3 observation key. A read view never computes an ecological year or turns a Genesis-only fixture into annual diagnostics. The *availability contract*, not an implicit null/zero, defines whether a diagnostic was really observed.

### 2.1 Field wrapper / reasons (DRAFT schema, not a shipped API)

For a field whose **source record requires** the value, failure to supply a valid typed value is a whole-observation refusal. For an optional diagnostic, require exactly one of these mutually exclusive states:

| State / proposed encoding | Semantics and validation |
| --- | --- |
| \`PresentSourced(value,sourceRef)\` | Exact typed field in admitted trusted fixture/report or confirmed completed-source observation; its source record and stage identified. |
| \`PresentComputed(value,sourceRef,calculationStage)\` | Actually computed by the admitted **qualified** model/report for this stage, with exact numeric type and diagnostic-phase provenance. A real computed numeric **0** uses this state and value zero. No UI recomputation. |
| \`NotEvaluated(reason)\` | Stage/system deliberately did **not** run the calculation for this row/phase (e.g., Genesis-only input, biologically dead target, p=0 roll skipped). No numeric value, including zero, permitted. |
| \`Unavailable(reason,sourceContext)\` | Data not present, unsupported or not admitted (e.g., no exact trusted annual output, absent stage aggregate, unknown measurement). Reason nonempty and typed. No guessed value. |

**Reason vocabulary proposed:** \`StaticGenesisNoAnnualEvaluation\`, \`NotLivingAtEvaluation\`, \`ConditionalRollNotDrawn\`, \`NotPartOfThisStage\`, \`NotRecordedInTrustedSource\`, \`StageAggregateNotSupplied\`, \`SourceImportUnqualified\`, \`FeatureNotImplemented\`, \`PolicyUndecided\`. Unknown reason code is a schema/version refusal; text messages are presentation-only, not programmable fallbacks. \`NotEvaluated\` describes known algorithm non-execution; \`Unavailable\` describes missing evidence/capability. A provided typed zero is neither of those. No invented truth-value from \`null\`, missing property or empty string. For fields with no meaning in a stage, use \`NotEvaluated(NotPartOfThisStage)\` if the stage is otherwise fully admitted; do not manufacture “not evaluated” when the source cannot establish this—then use \`Unavailable(NotRecordedInTrustedSource)\`.

**Required versus optional:** source/domain, trusted input identity, key, stable ordinal \`treeId\`, declared species/life/alive state, source X/Z position mapping, age, DBH, height and crown **must be present when actually supplied by the admitted vetted population** (as the frozen fixture does). A future mode lacking a genuinely mandatory biological measurement requires its own reviewed alternative schema; do not silently set zero or infer geometry/age. Declared \`standAreaHa\` f32 bits and geometry provenance required for stand statistics. Stand aggregates (other than validated roster count) may be \`Unavailable(StageAggregateNotSupplied)\` in Genesis-only input. An absent aggregate does not invalidate a complete **inventory**.
