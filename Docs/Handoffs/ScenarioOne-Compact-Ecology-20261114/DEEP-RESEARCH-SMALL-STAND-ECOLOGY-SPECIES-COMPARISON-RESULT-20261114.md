## Ranked alternatives, recommendation and reversal

1. **First — retain Sitka/Oak/Beech in model but phase tutorial attention**. **Moderate design confidence; low direct usability/Year40 evidence.** Supports D-059/D-060 while separately teaching Sitka management, Oak light/browse requirements, then Beech shade persistence.
2. **Second — retain three species, teach simultaneously**. Existing scope; may be useful if learner trials show no added cognitive load, but such a test does not exist.
3. **Third — Sitka+sessile Oak, separately scoped experimental option**. Possibly clearest early release/light-need contrast, but loses Beech teaching. Can't replace D-059 demo without explicit owner acceptance.
4. **Fourth — Sitka+Beech, separately scoped experimental option**. Potentially clearer shade/shelter lesson, but omits Oak light/browse contrast; ranking relative to Oak is low confidence and could reverse by study.

**Geometry is deliberately unranked for production.** Start any research comparison from authentic 20m/30m scratch worlds, add 25m *as new* sample, and test an ecologically **functional** surrounding context only with truthful source participation and authorised fixture construction. A 30m property contains a larger analytic Hegyi core than 20m but does not automatically become seed-connected, biologically validated, machine-accessible or educationally viable. Alternative finite plot is **an explicitly labelled training abstraction**, not an unbounded local forest.

**What would reverse choice?** 30–40-year native trajectories or 3D assets failing meaningful broadleaf distinction; a staged-three curriculum worse than two-species in user study; source-measured buffer difference large enough to reverse teaching causality; persistent contextual forest incompatible with save/boundary contract. These are tests, not existing facts.
