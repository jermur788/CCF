The staged-three option **shares biology** with simultaneous three; only explanation differs. Running all combinations would multiply effort without an identified causal question. **Do not release that grid as a task packet.**

1. **Freeze identity and source** from #460: actual 20m/30m starting age20 tree lists and source generator/seeds. First verify the external raw candidate JSON availability and hashes.
