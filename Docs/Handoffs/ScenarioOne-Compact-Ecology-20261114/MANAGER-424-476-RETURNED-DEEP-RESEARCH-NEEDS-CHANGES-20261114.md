## Blocking findings

The height table is **not an engine-derived 40-year forecast**. **Fix:** retract the height table or reconstruct with explicit baseline stand age vs elapsed simulation year, species establishment dates, actual code-derived outputs and primary sourced growth context; do not invent mature broadleaves.

**B-2 — Incorrect assertion that implemented seed rain, mast and natural regeneration do not exist.** Report `Code Path Audit` claims Sitka seed production absent/trivial, Oak/Beech seedfall not modelled and `only planting` produces recruitment. Current `Assets/ForestPrototype/ForestEcologyController.cs:1267–1300` computes species-specific mast states; `:1322–1360` computes species-segregated seed rain including maturity, crown and species seed-dispersal settings; `:1498–1521` admits **natural recruitment bands** from seed, light and suitability; `:454–498` runs competition, canopy, adult growth, browsing-adjacent regeneration growth, seed, natural establishment and promotion in the real annual sequence. Implemented **capability** is not proof of **observed** Oak/Beech natural recruits by Year 9; empty external seed donors can explain no broadleaf natural origin for the scratch starting configuration. **Fix:** cite exact source methods, identify model switches/initial donor conditions, distinguish capability from which species actually entered the scratch study and which offspring survived.

**B-3 — Incorrect assertions on browsing, storms and understorey.** Report says browsing not simulated, no windthrow/storm code and shrubs/moss absent. Current `ForestEcologyController.cs:38–41,190–204` exposes configurable browsing; `ScenarioOneDefinition.cs:56–58` sets a **0.2** scenario browsing-pressure calibration (not deer density) and `ScenarioOneManager.cs:439–444` applies it. `ForestEcologyController.Storms.cs` implements storm events and vulnerability, `ScenarioOneManager.Storms.cs` records deaths/events, **but** `ScenarioOneManager.cs:470–475` configures `StormModel.None` on *fresh new games*. `ScenarioOneUnderstorey.cs:5–66` simulates functional-group habitat proxies including mosses, ferns, shrubs; rendered sprite/mesh coverage is a **different, unverified** question. **Fix:** separately classify code implemented, current configured/active, captured native, user-visible 3D rendering and unverified; don't infer “not coded” from no storm in Year9 scratch.
