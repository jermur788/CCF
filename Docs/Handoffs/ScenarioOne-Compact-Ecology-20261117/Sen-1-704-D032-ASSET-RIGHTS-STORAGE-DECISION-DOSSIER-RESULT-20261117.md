## 5. Required source receipt and reproducible custody contract (proposed)

For *each distinct* source family, texture atlas, mesh export, material, source script, prefab and new `.meta`, future owner/operator produces a machine-readable receipt with:

1. Exact producer and legally authorised rights holder (natural person or organisation), date, creation method and all donor/reference assets with their licences; distinguish original generated pixels from purchased/imported material. Owner permission for internal work, private compiled beta, raw project and public source recorded as **separate** outcomes, with conditions and attribution.
2. Original editable master path (or explicit no-master justification), custodian and access group, authoritative source version, tool/version/plugins, deterministic recipe, dependency lock and backup/recovery location; no claims from filenames alone.
3. Actual source/export path, **SHA-256** and byte size; original Blender `.blend` and export FBX/PNG must be hashed independently. Record mesh/material counts, dimensions, source variant/state, expected importer settings and source input references.
4. Unity import product path, `.meta` GUID and GUID dependency map, shader/meta identifiers, asset/texture import settings, package versions + licence/notice collection; full build inclusion and explicit exclusion of external forbidden packs. Preserve historical GUIDs and record all new ones only after generation.
5. Storage channel (ordinary Git / LFS / controlled external), actual clone/fetch permission for non-author reviewer and CI, integrity/readback, offline restore test, retention/backup, and owner-authorised permitted distribution payload. No `Library` or package-cache archival disguised as source custody.
6. Independent nonauthor audit, Manager acceptance, and the exact **new** whole-world candidate dependency paths/hashes **before** the owner's exact-byte world attestation. The frozen [#676 candidate](https://github.com/jermur788/CCF/blob/8617587ebb7e118183bdd3eec7de5b099c371fdd/Docs/Handoffs/ScenarioOne-Compact-Ecology-20261117/Sen-1-676-COMPACT30-WHOLE-WORLD-MANIFEST-CANDIDATE-20261117.json) cannot be patched in place.

**Permission is not determined by the storage medium:** private Git, LFS or disk custody may each still expose unlicensed source bytes to collaborators. Conversely a licensed compiled build does not automatically allow `.blend` or loose FBX redistribution. Third-party vendor permissions must be read from the actual licensor; a CCF owner cannot sign rights they do not hold.
