## 5. New findings (non-blocking)

**N-1 (minor, wording consistency).** The Choice A summary row at L17 says W12(d)/(e) are removed "ONLY for exact listed files/**operations**". The operative text at L27 is file-scoped ("listed inert scene/content files and any individually authorised disposable tool ONLY"), and §3 is an exhaustive file list. "Operations" in the summary could be read as a second, operation-shaped scope. **Exact edit:** replace "files/operations" at L17 with "listed files and the one named disposable tool". No substantive change.

**N-2 (minor, lapse rule).** L37 says held work is "not silently ... discarded or pushed". The adverb preserves an authorised push route, which is correct if Stage P-3 answered YES, but the lapse rule should state the ordering explicitly: after expiry, no new push occurs unless the pre-answered P-3 channel permits it **and** the custodian records a release/renewal receipt. Otherwise "not silently pushed" can be read as permitting an ordinary push after expiry. **Exact edit:** append to L37: "After expiry, no push or merge occurs without a documented renewal; a P-3-permitted push of already-produced allowlisted bytes requires a custodian release receipt naming the expiry and the exact committed files."

**N-3 (minor, guard witness path).** L60 correctly makes a Year0-absent guard witness essential and L31/§3 J leaves it as a placeholder, but the sheet does not propose even a path class for it, while S/H/J each get an exact root. At signing time this is the one remaining tier-shaped blank that a reviewer cannot test for absence/ownership. **Exact edit:** add a proposed, explicitly optional witness root to §3 J — e.g. `Tools/Verification/Sen1Compact30GuardWitness/` plus an ephemeral scene path stated as "PROPOSED PATH, NOT AUTHORISED" — and state that witness bytes are never referenced by `ScenarioOneCompact30.unity` or the placement JSON. Rows 73–75 still stay open if it is not granted.

**N-4 (note, contamination check).** L35 forbids guards/juveniles at Year 0 and L60 requires a separate witness. For auditability, the future grant should require the placement JSON and the scene's dependency closure to be checked for any reference to the witness objects, so the "Year0 absent" native witness cannot be satisfied by a contaminated fixture. This is a test-design addition, not a defect in the target.
