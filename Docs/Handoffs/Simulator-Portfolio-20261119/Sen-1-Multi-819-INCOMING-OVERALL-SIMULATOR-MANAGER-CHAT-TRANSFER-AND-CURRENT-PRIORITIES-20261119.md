## 2. The simulator's actual product vision

The [Game Brief](https://github.com/jermur788/CCF/blob/main/Docs/Project/game-brief.md) states:

> **decide → advance time → walk the landscape → observe and experience consequences → understand why → decide again**

CCF is primarily a **3D sustainable forestry and land-management simulator** for smaller woodland/farm-forest managers. The player walks a physical, bounded property, assesses real tree conditions, chooses retention/harvest/planting/browse protection, approves a priced Work Plan, advances discrete ecological years, then sees woodland, economics and habitat actually change. Annual cause-and-effect, not a static spreadsheet or aesthetic-only scenery, is the core experience.

**Stage 1:** robust **continuous-cover forestry** and eight accepted future **independent Irish forestry scenarios** (D-078/079/080), in this intended learning order: Inherited Sitka Plantation; Working Mixed Forest; New Farm Woodland; Neglected Broadleaf Wood; Exposed Upland Forest; Atlantic Oakwood; Wet Woodland and River Valley; Complete Irish Forest Estate. Each world has its own stand, money and inventory; player knowledge carries forward. Future scenarios should add species and tree-life-stage learning. This is approved direction, **not eight implemented games**.

**Stage 2:** broader land management (fruit/nut trees first, then water/restoration/habitat, food, paths/fencing and construction), primarily simulated work rather than manual mechanics.

**Stage 3:** optional physical/manual solo execution of work that already shares the authoritative simulated outcome.

**Stage 4:** optional cooperative physical persistent world, not a present mandate. Do not build premature multiplayer, global shared economy, universal regional ecology or speculative abstraction that delays the first complete forestry scenario.

**Architecture concept:** `player judgement → proposed work → Pending order → explicit Work Plan Approval → executed work → authoritative annual ecology/economy → read-only history/reassessment`. Work choice, actor (contractor/landowner) and execution mode (simulated/manual later) are separate concerns. Proposals are **not Fell marks**; work is only committed by explicit approval; real outcomes must be visible in both source data and landscape. Label measured evidence, model inference and gameplay calibration honestly.
