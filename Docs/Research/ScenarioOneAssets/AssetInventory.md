# Scenario One asset inventory

Base/context a8596df; audit 5c389cc; 2026-10-07. AssetInventory.csv is an actual Unity AssetDatabase import inventory: 1,692 non-script imported assets, including 559 GameObjects, 718 Mesh assets, 156 Texture2Ds, 94 Materials, 139 TextAssets and four scenes. SourceAssetRegister.csv supplies 814 art/source entries with size, GUID, importer, texture max-size and adjacent source notes. Evidence/runtime_renderers.csv records 4,157 Renderer COMPONENTS in the initial runtime scene. This is not an enabled renderer, draw-call or visible triangle count: disabled LOD renderers are included.

Inventory fields retain imported hierarchy measurements and join provenance/import metadata. Scene/prefab dependency flags mean membership in the transitive dependency closure, not proof of screen visibility. Runtime catalogues/procedural geometry can have an empty asset path. Mesh triangle/vertex totals deduplicate meshes WITHIN each hierarchy and include every LOD, not just active LOD0. Material count sums slots across hierarchy, not unique materials/draw calls. GameObject bounds/root scale are import-space measurements; runtime biological height scaling can differ. Texture rows give actual imported dimensions; source register max-size is an importer limit. Pivot/origin was not numerically audited and is explicitly unknown in CSV, rather than invented.

Rows marked not individually rendered must be interpreted with the family-level reports. Licence status is unverified unless a recorded rights statement is independently checked; an 'original/procedural' README is provenance, not proof of redistribution rights. No asset was downloaded, generated, replaced or deliberately normalised in this task. Editor-generated material/settings rewrites are restored after all Editors exit.

Important coverage: procedural/current Sitka plantation variants; spruce seedling/pole/mature prefabs; oak sapling/young/mature and pruning sets; beech juvenile/young/mature representations; SectionFive ground flora and deadwood; recent litter/brash/grass/rush assets; shelter and marking/navigation/UI generated components; tracks and prototype work structures. Missing specialised future machinery/storm/BioTree assets do not create a current mechanic requirement.
