## 2. Recommended order

1. **Training mode (Q2)** — small, reuses everything, needs M2 + storms (already in the Scenario One plan), and directly multiplies the learning value of the finished scenario. Can start while Stage 2 is being scoped.
2. **Stage 2 — Expanded Land-Management Simulation, first slice** — begin with the items Scenario One already points to: **deer fencing** and **habitat retention** (bio trees, standing deadwood), then **paths/access**. Each is a separate accepted packet (D-044 says each needs its own packet). Same property, so the history/diary carries over.
3. **Asset/art pass** — continuous, but a dedicated pass after Stage 2 slice 1, when new structures exist.
4. **Scenario Two** — once Stage 2 has proved the land-management architecture *and* a second region can be built from data. Choose a scenario that tests the separation (e.g. a broadleaf or mixed native woodland), not just "more Sitka".
5. **Survival / construction (physical)** — after D-033 is decided. Stage 3 optional manual execution reuses the same authoritative tasks (D-009).
6. **Multiplayer preparation** — only when a milestone needs it (D-022, D-034). Keep the existing boundary discipline meanwhile.

## 3. Why not Scenario Two first

- It would duplicate unfinished teaching infrastructure (progression, history, completion) before it is proven on Scenario One.
- It forces regional generalisation (species, climate, markets) before the land-management architecture is broadened (D-007).
- Its asset cost is highest and its learning value is lower than that of a trained player going deeper on a familiar place.

## 4. Decision required

Accept the order 3 → 5 (slice 1) → 6 → 1 → 2 → 4? Or put Scenario Two earlier for content variety? A product (user) choice.
