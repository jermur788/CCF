# Scenario One — forestry terminology audit (Workstream A4)

**Status:** audit [REPO] plus proposed first-use wording [INF]. Not decision authority. **No string has been placed into production.**

Rules for the proposed wording:

- One or two sentences, at the moment the term is first needed.
- Forestry-correct, but not a textbook.
- Must not claim an ecological mechanism the simulation does not have (D-020).
- Where the game simplifies, say so briefly ("in this game…").

## Terminology consistency recommendations [INF]

1. Use **Fell** for the mark, **thinning** for the job type, and avoid **harvest** in marking messages. "Marked P0712 as harvest" should read "Marked P0712 to fell".
2. Use **clearance** only with an explicit affected list that names tree regeneration. Replace "regeneration cohort(s) removed" in the Annual Review with "area(s) cleared — young trees and ground plants removed".
3. Avoid internal words in visible strings: *cohort, juvenile, promotion, occupancy, CI*. Use *seedling group, young tree, joins the canopy, competition*.
4. Show species display names, not ids ("sessile oak", not "sessile-oak").
5. Use one name for the checklist ("Lessons") and keep "Objectives" for forest goals.

These are copy changes to UI strings only. They have no simulation or save impact, but they touch `UI/*` and two manager strings. See Packet 1 in `ImplementationRoadmap.md`.
