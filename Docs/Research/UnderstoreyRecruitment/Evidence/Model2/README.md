# Model2 trial evidence

This folder contains the paid model2 trial, independent state/geometry/accounting checks, measured serialization/timing, and final regression results. Historical Evidence and Evidence/Continuation were preserved. Exact diagnostic source hashes and run modes are recorded in result JSON.

`regression-initial-results.json` records the initial 17/23 suite. Its six failures were diagnosed before correction; final results must be read from `regression-final-results.json`. `economy-reset-save-failure.json` records the later genuine immediate-reset save defect. Current state checks include the production correction. See Model2Handoff.md for the final acceptance status and detailed failure accounting.

The 33-world matrix preceded the final exact-point distance pruning and the immediate-reset save fix. The six targeted worlds and final performance run used the distance pruning. Final state/geometry/equivalence and the full regression suite ran after the reset-save fix. These later changes preserve existing populated grid values and survival equations; matrix setup explicitly initializes all covers. The century matrix is not claimed to have been rerun after the final save-capture fix. Before-pruning timing and before-reset state results are labelled separately.

Natural amounts are relative occupancy, not priced stems. Cause losses are cumulative in century CSVs and annual in cell-ledger checks. Planted counts and cash are exact under existing work/economy rules. Stand columns repeated in species rows are aggregated once, not three times. Background cover means are not the patch-weighted exposure used for survival.

Timing uses simulation-only loaded worlds, four repetitions and a declared first-repetition warm-up exclusion. These data do not measure visual FPS. Large-patch builds and point queries are separate stress workloads. Actual save-byte comparisons remove only the five added fields from the same world; full sample saves and full Editor logs remain under ignored Build rather than this review folder.

The final handoff and Model2Trial.md document reproduction and remaining [C]/[D]/[I] parameter decisions. Passing mechanics is not ecological parameter approval or main integration.
