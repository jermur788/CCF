**UI:** present two areas on one coherent session with area-specific map and one Work Plan. Area labels, counts, BA, modelled competition and Year+1 must reflect real per-area state, not copied one-area map snapshots. Present synthetic/no cross-edge/no site variability truthfully; normal UI hides secret keys while preserving server fences. Keyboard and 1280×720/browser zoom/accessibility require Tier 2. #882 focus repair must be qualified before reliance.
