# Requirements — numerical model quality gates, not a speculative QA programme
**Status DRAFT; mark only from actual evidence.**
- [ ] C01 Exact MA-A/MA-B initial radius source and annual physical radius update traceable with commit+fixture+unit provenance.
- [ ] C02 Potential/open-grown radius distinguished from actual realised crown in current stand. The 1988 potential allometry is not misrepresented as a dense plantation observation.
- [ ] C03 An independently justified Sitka realised-crown method considers tree size, local neighbour competition/space, stand context and plausible age/thinning history, or documents unavailable inputs/limits.
- [ ] C04 Initial and annual radii share a consistent biomechanical/model history; no abrupt instant gap filling or delayed artefact from assuming initial CI=0.
- [ ] C05 No universal nonoverlap/Voronoi or per-tree area cap is silently added; actual crowns may legitimately overlap.
- [ ] C06 No forced screenshot outcome. For real crowns, measure actual **clipped union canopy cover**, not naive total area, at year 0 and after genuine 10-Fell/3-year cases, in both areas.
- [ ] C07 Compare crown distribution/release to empirical measurements/ranges, with provenance, uncertainty, and domain transfer stated. Clear distinction between field-based, transferred and game-tuned values.
- [ ] C08 Exact old P0/Legacy40/Reference Future v1/saves and frozen derived fixture preserved; any new scenario/manifest/model version and compatibility recorded.
- [ ] C09 No changes to SVG canopy artwork/map UI for this task; model-authoritative physical outputs drive display and no false area mixing.
- [ ] C10 Narrow deterministic check of crown radius floor/potential bounds, reproducible trajectories and Work Plan unchanged; no broad unrelated test programme.
- [ ] C11 Direct source commit, model-owner evidence approval, independent scientific qualification if needed and owner playtest separately reported; no automatic G2 acceptance.
