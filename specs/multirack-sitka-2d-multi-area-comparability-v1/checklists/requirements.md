## R. Design requirements — none tested

- [ ] **R-01 — Multi's purpose:** sample player treatment in one area and propose conservative independently source-supported treatment in **multiple** comparable areas; one-area manual demo alone is incomplete.
- [ ] **R-02 — distinct fixture and scope:** independent source/manifest with stable case-sensitive IDs and actual source-scope data for sample, at least two genuinely comparable targets and one DIFFERENT/UNKNOWN control, without altering protected original.
- [ ] **R-03 — committed source:** all data current committed source-year, exact experiment/model/version/precision and per-tree live status; no preview/reported/uncommitted frame becomes authority.
- [ ] **R-04 — source feature validity:** present units/availability/provenance for selected matching attributes and explicit missingness; no invented XY/site/wind/soil/density source property.
- [ ] **R-05 — independently qualified predicate:** COMPARABLE/DIFFERENT/UNKNOWN with reviewed calibration, explicit exclusions and version; no simple species/age/area proxy or arbitrary threshold.
- [ ] **R-06 — fail closed:** insufficient match/fixture/G1 source DISABLED / Manual / NotCovered, no automatically extended proposal.
- [ ] **R-07 — real local sample:** per-ID live current-year player selection/retain/release decisions and rationale within a proven source sample scope; no all-tree treatment from choosing area.
- [ ] **R-08 — itemised target proposal:** every suggested exact live tree carries sample-source scope, target scope, matched/excluded/unknown reasons, per-area coverage and provenance; still hypothetical.
- [ ] **R-09 — player override:** explicit review/reject/accept/manual override per target and area before any prescription; unknown areas stay manual.
- [ ] **R-10 — prescription/PendingWork:** proposals become orders only after separate prescription review/approval; manual additions may create validated ordinary PendingWork directly; proposal edit invalidates approval.
- [ ] **R-11 — sole commitment:** one consolidated whole-batch Work Plan approval and a separate user Execute; proposal, selection, prescription and pending state never Fell.
- [ ] **R-12 — G2 real atomic work:** whole-batch legal current-year Fell with cause/event/rollback/once-only protection; cross-area partial transaction not accepted as all-area success.
- [ ] **R-13 — real per-area annual result:** actual source survivors/competition/growth/natural mortality, before/after per-area counts/BA and per-ID work events, year y versus y+1 distinguished.
- [ ] **R-14 — repeat and stale rules:** renewed sample/source review each cycle, no old automatic proposal replay; warning/consent/zero-Fell stale cancellation of unexecuted work on year advance.
- [ ] **R-15 — honest presentation:** accessible source/proposal/executed status, unknown comparisons, manual fallback; absent costs UNAVAILABLE not zero, no durable save claim.
- [ ] **R-16 — formal gates:** G1 source/fixture proof, separate approved spec, G2 source proof, authorised exclusive physical/source lane, independent tests and Manager acceptance before implementation/integration.
