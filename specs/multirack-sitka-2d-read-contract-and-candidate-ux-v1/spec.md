### 3.1 Source-to-adapter handoff and authority proof

1. A lawful custodian admits original fixture bytes under the existing source trust process, or lawfully identifies **one genuine #725 completed report** tied to the same admitted fixture, or later one **actual #789 single committed** annual state. The read adapter **never** takes an arbitrary browser object or rounded table as a biological source. The legacy #784 F3 private key is **not** an exportable contract.
2. The adapter builds a private candidate from **one** source transaction; copy complete and detached data, source-native numeric words and exact full roster. It records positive proof of source origin and binds its report/stage to that origin. A report without independently validated binding to fixture/domain/models/year **cannot** be joined to Genesis. Do not fabricate an engine experiment ID for legacy #725 if the old report does not supply one: H0 uses a source-verified report-origin association; later dynamic private experiment/generation is required only when actually present.
3. Validate *all* identity, provenance, row, bit, stage and aggregate constraints before publication. Stage diagnostics absent in source remain unavailable; distinguish a deliberately skipped evaluation from computed zero. No source mutation or callback to annual engine during conversion.
4. Atomically expose **one immutable active-current full read frame only from trusted Genesis or committed AfterMortality** with an adapter-owned opaque local read revision; compare previous committed-source identity/revision before delivering a replacement. Attach source-proved Before/PostGrowth only as read-only children of a completed transaction; never independently activate or increment revision on stage navigation. No partially published array, late stream update or setter on the engine's writable tree objects. A frozen *presentation object* alone is not proof of trusted origin: the producer boundary must be independently source-audited.
5. On rejection publish **no new frame**. If none was admitted, show refusal and **no map, ID list or stand measures**. If an old frame was valid, display it only with explicit “previous accepted frame — current update refused” indication and disable current-year draft edits; never silently pass the old frame as the new one.
