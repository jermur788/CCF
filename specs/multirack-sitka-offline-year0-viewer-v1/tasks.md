## 3. Exact future Core↔A handoff contract (logical, not shipped API)

**Core delivers** an immutable detached single **Genesis** observation or a typed refusal. It carries:

- Fixed read-schema version, vetted full fixture/bundle identity, source domain/fixture/catalog/SHA, source class/disclosure, geometry/transform/area, declared seed/algorithm/growth/RNG model; explicit stateEcologicalYear=0 and sourceStage=Genesis. These bind a **full immutable observation key**, not a new live generation or commit number.
- Complete 100-row registered-ID roster (one per ordinal ID), xMm/yMm integer, verified centred f32 X/Z bits, species/stage/demand/living state, sourced age/dbhCm/heightM/crownRadiusM bits and explicit optional availability.
- Stage-aligned validated **100 registered / 100 living** inventory count; no pretend computed source BA/Dq/RD/Nha; no pre-growth CI or hazard at Year0.
- Refusal messages with typed reason and preserved prior valid UI. No partial record exposure.

**A consumes** the immutable object and generates only view primitives, UI focus/camera and inspection events:

- local XY display = source raw mm / 1000 (east-right, local north-up); if receiving only centred source X/Z after trusted Core transform, +15 metres is a **view-only** conversion under exact transform ID.
- crown pixel radius = source crown **radius** in metres × CSS pixels-per-metre (NOT diameter).
- stem hit-test nearest centre, ordinal tie; A may send **(selectedTreeId, fullObservationKey)**, no mark/plan/source mutation.
- display-rounded values and CSS coordinates are **never fed** into Core numeric authority or a future engine.

Future C may someday consume A selection, but F2 eligibility semantics and local draft marks are entirely absent here. Future D Year0/Year1 H0 comparison would need its **own separately qualified ReportOnly bundle** and full shared lineage checks; T00 cannot silently approve this.
